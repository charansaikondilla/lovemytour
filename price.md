## 3. Website Technical Specifications & Version

- **Current Version:** `v2.4.0`
- **Architecture:** Single Page Application (SPA) with Hash-based Client-Side Routing (`script.js` → `handleRoute()`).
- **Core Technology Stack:** 
  - **HTML5:** Semantic, accessible layout structuring.
  - **Vanilla CSS3:** Custom CSS variables design tokens, dark/light ambient aesthetics, glassmorphic UI cards, responsive flexbox/grid layout.
  - **Vanilla JavaScript (ES6+):** Pure client-side routing, instant search & filter algorithms, dynamic DOM rendering, zero heavy library bloat.
  - **Deployment Ready:** Netlify / Vercel static host optimized (`dist/` build output).
- **Mobile & Safari Compatibility:** Optimized for WebKit engines (iOS Safari, Chrome-iOS) with correct pathing, image lazy loading (`loading="lazy" decoding="async"`), and touch-friendly mobile navigation drawer.
